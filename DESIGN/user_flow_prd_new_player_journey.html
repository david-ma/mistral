# User Flow: New Player Journey (Photo Hunt) ## Goal Design a frictionless mobile experience for a first-time user, moving from discovery to repeated engagement. ## The Flow 1. **Screen 1: Event Landing** - User arrives via URL. - Simple event description and "Join Hunt" button. - No login required. 2. **Screen 2: Prompt 01 (First Capture)** - User sees their first specific prompt. - Primary action: "Open Camera" or "Upload Photo". 3. **Screen 3: Prompt 02 (Progress)** - Success state for first photo. - Immediate display of the second prompt to maintain momentum. 4. **Screen 4: Save Progress (The Hook)** - After the 2nd photo, the user is prompted to create an account to "Save your Hunt". - Explains the benefit: "Resume on any device and see your gallery." 5. **Screen 5: My Attended Events** - After signing up, user lands in their profile. - Shows the current active event they just joined + past history. 6. **Screen 6: Prompt 03 (Post-Auth)** - User jumps back into the hunt to complete their third prompt. ## Design Principles (Uncodixify) - **Midnight Mono** styling: Dark, high-contrast, strictly functional. - No gradients or "fluffy" copy. - Clear status indicators (e.g., "1 of 5 prompts complete"). - Large, reliable tap targets for mobile camera interaction.
