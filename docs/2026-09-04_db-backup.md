# DB backup script (2026-09-04)

## Goal

Add a simple `bun run db:backup` for the local SmugMug MariaDB (docker compose `db`), modelled loosely on Micronet’s backup but without modes, table blacklists, or progress logging.

## Approach

- Script: `scripts/backup-database.ts`
- Package script: `db:backup`
- Pipeline: `docker compose exec -T db mariadb-dump … | gzip > tmp/smugmug_backup_<stamp>.sql.gz`
- Defaults match `docker-compose.yml` / `drizzle.config.ts` (`smugmug` / `smugmug_user` / `smugmug_password`)
- Optional env overrides: `SMUGMUG_DB_NAME`, `SMUGMUG_DUMP_USER`, `SMUGMUG_DUMP_PASSWORD`, `SMUGMUG_BACKUP_DIR`

## Operator

Requires the compose stack running (`docker compose up -d` or equivalent).

```bash
cd /usr/local/dev/Thalia/websites/smugmug
bun run db:backup
```

Restore example is in the script header comment.
